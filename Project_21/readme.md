**Omnifood Landing Page**

A simple responsive food delivery landing page built using HTML, CSS, jQuery and a little bit of animation libraries.
This project was made while practicing frontend development concepts like responsive layouts, grid systems, smooth scrolling and UI design.
The main goal of this project is to showcase a professional food delivery business using HTML, CSS, jQuery, animations, and responsive design techniques.

**Features**
.Fully responsive layout
.Smooth scrolling navigation
.Animated sections using AOS
.Responsive grid system
.Pricing section
.Customer testimonials
.Contact form
.Clean footer with social icons

**Technologies Used**

**Smooth Scroll**

Smooth scrolling is implemented using jQuery animate method.

$("html, body").animate(
{
scrollTop: $(hash).offset().top,
},
800
);
